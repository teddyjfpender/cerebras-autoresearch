# Kernel research

Optimize compute, communication, and complete resident chains. Hold each
profile's semantics, input/output types, PE budget, and timing scope fixed.
Record memory costs. Layout/precision/model alternatives need distinct profiles.

The default editing surface is a CSL candidate workspace. Keep pinned `.deps/`
sources pristine. Preserve callback, routing, memcpy, and initialization contracts.
Review equivalent timed work even when numerical outputs pass; a cached warmup
answer or skipped repetition is not an optimization of the specified workload.

Run all numerical families and fresh confirmation before retaining a cell.
Cross-shape/general claims require the relevant suite and worst-cell guard.
